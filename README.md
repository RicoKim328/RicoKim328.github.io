# RicoKim328.github.io

Personal blog (Jekyll + GitHub Pages).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000

## Content

- Add posts under `_posts/` as `YYYY-MM-DD-title.md`
- Profile / logos live in `assets/images/`
- Categories in the sidebar are generated from post front matter (`category` or `categories`)
